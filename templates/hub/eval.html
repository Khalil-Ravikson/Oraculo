Taxonomia de metadados das ingestões (UEMA)

Cada chunk no Redis deve carregar metadados taxonômicos indexados. Defina as tags na ingestão (LlamaParse ou scripts de carga):

1. eixo — tema principal (Institucional, Ensino, Pesquisa, Extensao, Sistemas).
2. setor — pró-reitoria/diretoria dona do dado (PROG, PROEXAE, PPG, CTIC, Reitoria, Geral).
3. tipo_doc — tipo do arquivo (Edital, Calendario, Resolucao, Manual, Contatos).
4. ano — ano letivo (2025, 2026). Barra calendários obsoletos.
5. campus — campus aplicável (Sao_Luis, Caxias, Imperatriz, Todos).

Na busca, o QueryTransformService lê o histórico do chat e reescreve a query anexando filtros dessa taxonomia (ex.: @ano:{2026} @tipo_doc:{Calendario}).

Ingestão automática via LlamaParse

Converte PDFs complexos em Markdown estruturado — ideal para tabelas de calendários e editais. Arquivos em dados/tmp/ podem ser processados pelo pipeline local.

# Ingestão via LlamaParse from src.rag.ingestion.pipeline import IngestionPipeline from src.infrastructure.settings import settings # configure LLAMA_CLOUD_API_KEY no .env pipeline = IngestionPipeline.build_auto( file_path="dados/tmp/documento.pdf", doc_type="edital", ) result = await pipeline.run_async( file_path="dados/tmp/documento.pdf", doc_type="edital", label="EDITAL 2026", ) print(f"ok={result.success} chunks={result.chunks_saved}")
